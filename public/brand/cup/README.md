# AUSDAUER CUP – Logo-Dateien

Erzeugt mit `npm run brand:cup -- <Saison> <Anzahl Läufe>` (z. B. `npm run brand:cup -- 2027 9`). Alle Schriften sind in Pfade umgewandelt, die Dateien funktionieren ohne installierte Fonts (Druckerei, Textildruck, RaceResult).

| Datei | Einsatz |
|---|---|
| `ausdauer-cup-serie-*.svg` | Serienlogo mit „Laufserie Siegerland“, Serienleiste und Saison – Urkunden, RaceResult, Webseite, Flyer |
| `ausdauer-cup-*.svg` | Kompakt (AUSDAUER + CUP-Plakette) – Banner, Startnummern, Medaillenband |
| `ausdauer-cup-gestapelt-*.svg` | Gestapelt – T-Shirt-Rücken, Hochformate, Beachflag |
| `ausdauer-cup-siegel-*.svg` | Rundes Siegel – Urkunden-Siegel, Brust-Logo, Medaille, Sticker |
| `ausdauer-cup-icon*.svg` | Icon – Social-Avatar, Favicon, Stempel |

Farbstellungen: `farbig` (auf Weiß), `negativ` (auf Ink), `schwarz` (Einfarbdruck), `weiss` (auf Rot/Ink, Plakette ausgespart).
