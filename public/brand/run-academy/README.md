# Run Academy – Logo-Dateien

Erzeugt mit `npm run brand:subbrands` (gleicher Generator wie der AUSDAUER CUP). Schrift in Pfaden, funktioniert ohne installierte Fonts.

| Datei | Einsatz |
|---|---|
| `run-academy-*.svg` | Standard: Plakette + „RUN ACADEMY“ + „Besser. Laufen. Lernen.“ |
| `run-academy-gestapelt-*.svg` | Gestapelt: Shirts, Hochformate |
| `run-academy-icon*.svg` | Plakette allein: Avatar, Favicon |

Farbstellungen: `farbig` (auf Weiß/Paper), `negativ` (auf Ink), `schwarz` (Einfarbdruck), `weiss` (auf Ink/Fotos).
